# Minha Lista de Tarefas (React + Back4App)

Aplicação de lista de tarefas feita em React com persistência de dados no Back4App.

## Como rodar localmente
1. Instale as dependências com `npm install`.
2. Crie um arquivo `.env` a partir do `.env.example` com as chaves do Back4App (`VITE_APP_ID` e `VITE_REST_KEY`).
3. Rode `npm run dev`.
